# Removal and continuity check

Before accepting a deletion, search callers, persisted contracts and shipped
resources. Verify that missing data fails by name and historical references stay
addressable. Do not migrate, rewrite or remove historical outputs, retained runtime
bindings, project installations or unrelated skills as a side effect. Destructive
owner actions need separate explicit authority and preview/backup; a changed
product default does not authorize cleanup of prior user material.
