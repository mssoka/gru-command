# Evidence honesty check

For each completion/review claim, identify the exact artifact or executed command,
full canonical tested/reviewed head, outcome and limitation. Read the underlying
code and receipts, not just an author's summary. Stale head, skipped checks,
queued reviewer prompts, fallback PASS and native READY are distinct states.
Keep unknowns explicit; a deterministic package/render fixture proves package
mechanics, not a paid model execution or production session cutover.
